# Deploy-To-Azure-Aeb-Apps
This repository provides templates, scripts, and workflows to automate the deployment of applications to Azure App Services (Web Apps) using GitHub Actions. It includes:

Infrastructure-as-Code examples for provisioning Azure resources.
CI/CD pipelines for building and deploying .NET, Node.js, Python, and Java apps.
Integration with Azure CLI, Azure Resource Manager (ARM), and GitHub Secrets for secure deployments.
Support for staging slots, environment variables, and custom domains.

# Ideal for developers and DevOps teams looking to streamline application delivery to Azure with minimal manual steps.
